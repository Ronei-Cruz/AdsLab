# 📊 Comparador de Produtos - MVP

Um projeto web interativo e responsivo focado na **comparação detalhada de 3 produtos** do mesmo setor para auxiliar o usuário na tomada de decisão de compra. 

Este MVP (Minimum Viable Product) foi construído utilizando **HTML5, CSS3 e JavaScript Vanilla**, sem dependências ou frameworks externos, com uma arquitetura de arquivos limpa e modular.

---

## 🚀 Funcionalidades

- **Matriz de Comparação Lado a Lado:** Visualize rapidamente preços, performance, durabilidade, avaliação e recursos dos 3 produtos.
- **Filtros Interativos via JavaScript:** 
  - Destacar o produto de **Menor Preço**.
  - Destacar o produto de **Maior Performance**.
  - Destacar o produto de **Maior Durabilidade**.
- **Badges de Destaque:** Identificação visual para *"Melhor Custo-Benefício"* e *"Escolha do Editor"*.
- **Cards com Detalhes dos Produtos:**
  - Imagem e descrição detalhada.
  - Lista de **Prós e Contras**.
  - Botão direcionando para a loja externa com link de afiliado/compra.
- **Seção FAQ (Accordion):** Dúvidas frequentes retráteis com JS.
- **Layout 100% Responsivo:** Otimizado para dispositivos móveis, tablets e desktops (Mobile-First).
